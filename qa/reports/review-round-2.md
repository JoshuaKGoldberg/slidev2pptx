## Results

Every deck was then built and rendered again with round 2's fixes, and with round 2's starting code (d841e65) for comparison.
Both used the same renderer, as PowerPoint's own variation made about 200 states look worse in the first full rerun:

- PowerPoint for Mac drops its font's kerning from random paragraphs, more often right after it launches, and differently in each render of the same file, so a line comes out 0.6-3.7% wider.
  The harness now has PowerPoint kern before rendering (7470715) and renders each state that didn't pass up to twice more, keeping its closest render (f8a1f4d): 236 baseline states and 158 current ones kept a later render.
- PowerPoint now and then stalls mid-export, busy but answering nothing, which the idle-hang watchdog missed.
  Exports now have a time limit, after which PowerPoint is killed and the export is tried once more, and the render lock records its owner (904ceea).
- PowerPoint draws `b="1"` on a family whose only installed face is bold (Nunito Sans) about 1.5% narrower in some sessions and not others, which re-rendering in the same session doesn't help.

Across the 6,632 click states of 77 decks:

| Code                      | Pass          | Review     | Fail      |
| ------------------------- | ------------- | ---------- | --------- |
| Round 2's start (d841e65) | 6,049 (91.2%) | 497 (7.5%) | 86 (1.3%) |
| After round 2's fixes     | 6,361 (95.9%) | 229 (3.5%) | 42 (0.6%) |

350 states moved to a better verdict and 35 to a worse one.
The worse ones showed three regressions from round 2's own fixes, now fixed:

- 136946c: exact spacing at a pitch near single spacing is unpredictable, as whether PowerPoint puts the first baseline by its spacing multiple's rule or by single spacing's flips with the font size (measured from 20 to 72 pt), so lines mixing fonts at one size are spaced by a multiple of their measured pitch instead.
- e97f140: a list item starting with an emoji lowered among text, which is written 1.5 times larger, drew its number 1.5 times too large.
- 3288df8: pictographs past the Basic Multilingual Plane, like 🏗, are only in emoji fonts, so they're placed as emoji even without U+FE0F.

Of the rest, five are Nunito Sans' narrower session, five are emoji-only lines at 150-250px sitting about 0.01em from where round 2's starting code put them, and the others are left to round 3, whose reviewers compare every state against this baseline.
Exact spacing near single spacing stays open for paragraphs mixing sizes, which still need it.
